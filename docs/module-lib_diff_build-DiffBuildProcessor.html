DiffBuildProcessor

lib/diff_build~ DiffBuildProcessor

差分ビルド処理を行うクラス。
Git の差分データを基に対象を絞り、対象ファイルと依存関係にあるファイルや所属する同グループのファイルを選定、選択。
加えて、最終選択されたファイルをストリームに渡す。
